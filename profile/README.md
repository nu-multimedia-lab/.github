# 長崎大学マルチメディア研究会

長崎大学のゲーム制作サークルです。Unity を中心に、ゲームジャム形式でチーム制作をしています。
イラスト・3D モデリング・DTM など、ゲーム以外の創作をしているメンバーもいます。
