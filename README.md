# .github（nu-multimedia-lab 共通リポジトリ）

長崎大学マルチメディア研究会 GitHub organization の共通ドキュメント置き場です。

| ファイル | 内容 | 誰が読む |
|---|---|---|
| [`profile/README.md`](profile/README.md) | org トップページに表示される紹介・作品一覧 | 外部の人（新入生・採用担当など） |
| [`docs/HANDOVER.md`](docs/HANDOVER.md) | 引き継ぎ書（権限・年間スケジュール・ルール） | 部長・副部長・Owner |
| [`docs/RELEASE_GUIDE.md`](docs/RELEASE_GUIDE.md) | 作品を Releases / unityroom で公開する手順 | 作品を公開したい人 |
| [`templates/GAME_README.md`](templates/GAME_README.md) | ゲームリポジトリ用 README の雛形（[unity-game-template](https://github.com/nu-multimedia-lab/unity-game-template) の README と同じ内容） | テンプレートを使わずにリポジトリを作る人 |

変更はすべて PR で出してください（main への直接 push はできません）。承認は不要で、出した本人がマージできます。

> このリポジトリは public です（org プロフィールを表示するため）。
> パスワード・API キー・個人の連絡先などは **絶対に書かないでください**。
